## 五、改动交付文件后

```powershell
# 刷新 文件清单.json 中的哈希，再校验
& $py -X utf8 "_00_工作区\测试与证据\update_manifest.py"
& $py 检查文件.py
```

> ⚠️ `文件清单.json` **不登记自身**（否则哈希自引用死循环）。因此不要手工往清单里加 `文件清单.json` 条目。
> ⚠️ 用 WPS 打开并保存 `技术报告_*.docx` 会改变其哈希，导致校验报"内容改变"。现场请只跑检查、不编辑。
